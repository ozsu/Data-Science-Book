# Principles and Foundations of Data Science

Companion repository for *Principles and Foundations of Data Science* by M. Tamer Özsu
(David R. Cheriton School of Computer Science, University of Waterloo).

**Website: https://ozsu.github.io/Data-Science-Book/**

## Contents

| | |
| --- | --- |
| [Errata](errata.md) | Corrections in page order, with the printing each applies to. |
| [Review Questions](questions/index.md) | Per-chapter questions for self-study and for instructors. |
| [Slides](slides/index.md) | Per-chapter lecture slides, released as prepared. |
| [`ds-references.bib`](ds-references.bib) | The book's full bibliography in BibTeX. |

## Reporting an error

Corrections are welcome — typographical, mathematical, bibliographic, or factual.
[Open an issue](https://github.com/ozsu/Data-Science-Book/issues/new) with the page
number, what the text reads, and what it should read, or email
[tamer.ozsu@uwaterloo.ca](mailto:tamer.ozsu@uwaterloo.ca) with "DS book errata" in the
subject line. Please include the printing, which appears on the copyright page.

## Reuse

Instructors are welcome to adapt the slides and review questions for teaching, with
attribution to the book. The material here is supplementary; the text of the book itself
is not included in this repository and remains under the publisher's copyright.
